# Resources Overview

This directory indexes external resources for the FAU Marine Robotics Club (MRC), especially items stored in Google Drive, and connects them to this documentation repo.

The goal is to keep **large or binary artifacts** (CAD, videos, datasets, PDFs) in Google Drive or dedicated data repositories while this repo holds:

- High-level descriptions of what each resource is.
- Links to the authoritative source in Google Drive.
- Pointers to where each resource fits into the WAM-V, RoboBoat, RobotX, TowFish, and AUV documentation.

Current subpages:

- `google_drive_inventory.md` – high-level index of the main MRC Google Drive structure.
- `papers_and_reports.md` – list of published papers and design reports with links.
- `wamv_and_auv_cad.md` – key WAM-V and AUV CAD assemblies and specifications.
