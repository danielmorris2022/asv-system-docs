# Field Checklists

Standard checklists used before, during, and after field operations.

## Pre-Departure Checklist

- Items to bring (hardware, batteries, tools, safety gear).
- Checks to perform on each platform before leaving.

## On-Site Setup Checklist

- Steps for setting up base station and platforms.
- Network checks, GPS lock, sensor functionality.

## Pre-Mission Checklist

- Final checks before running an autonomous mission.
- Failsafe configuration and safety observers.

## Post-Mission Checklist

- Shutdown procedures for platforms and base station.
- Data offload and quick review.
- Notes and any issues to document for later.
