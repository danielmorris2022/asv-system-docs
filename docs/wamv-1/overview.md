# WAMV-1 Overview

WAMV-1 is a WAM-V 16 autonomous surface vehicle used as a general-purpose development and testing platform.

- Equipped with bow thrusters for fine maneuvering and low-speed control.
- Does **not** carry the dedicated depth sensor or weather station.
- Typically used for navigation, control, and autonomy experiments where bow-thruster-assisted positioning is useful.
